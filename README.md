# Project Overview
This project is to make a pendulum and collect data from it. It is for my PHY180 Classical Mechanics course. The pendulum consists of a mass attached to a structure. This repository is used to take videos of the pendulum and do all the processing.

## Getting Started

Python with the OpenCV, Numpy, Matplotlib, and SciPy libraries is required

Ensure Git is installed and setup to work with he repository

Clone the project repository to your local machine and navigate into the directory:
```
git clone https://github.com/VedantGithub123/Pendulum-Tracker.git
cd Pendulum-Tracker
```

## Usage
1: Modify "mass-color-filter.txt" to the correct bounds for your mass
2: Modify "reference-color-filter.txt" to the correct bounds for your reference block
    i:   The reference block is at the pivot point
3: Add a video to folder "filter-testing-images" to test the filters. The image shown will be the first frame of the video
4: Modify "frame-rate.txt" to the frame rate of the videos
5: Modify "uncertainties.txt" to the correct type B uncertainties
6: Add all videos to the "videos" folder
    i:   The video name should just be "length-initial angle-trial number-video"
    ii:  For example, if the initial angle is 25.78 degrees and the length is 10.5 and the trial is 12, the file name should be "10-5-25-78-12-video"
    iii: If the initial angle is a whole number like 25 degrees and the length is 10, use "10_0_25_0_12-video"
    iV:  There can be any number of decimal points
7: Run "videos-to-position-data.py", you should now have text files in folder "position-data"
    i:   These new files will have the same name as the video, except replacing "video" with "position-data"
8: Run "position-data-to-graphs.py", you should now have images in folder "position-graphs"
    i:   The images will have the same name as the video, except replacing "video" with "graph"
    ii:  These graphs will show all parameters and a line of best fit along with the period, q-factor, standard deviation,  
9: You should also have images in folder "period-graphs"
    ii:  Another graph will be created which shows the period vs length
    iii: Another graph will be created which shows the period vs angle
    iV:  A 3d graph will be created which shows period vs length/angle
10: You should also have images in folder "dampening-graphs"
    ii:  Another graph will be created which shows the dampening vs length
    iii: Another graph will be created which shows the dampening vs angle
    iV:  A 3d graph will be created which shows dampening vs length/angle
11: You should also have images in folder "q-factor-graphs"
    ii:  Another graph will be created which shows the q-factor vs length
    iii: Another graph will be created which shows the q-factor vs angle
    iV:  A 3d graph will be created which shows q-factors vs length/angle

Position data file format:
Time1 Angle1
Time2 Angle2
...
TimeN AngleN


## Major Scripts
### `videos-to-position-data.py`

This script processes every video in the `inputs/` folder. It reads the mass and reference color filters from `config/`, converts each video frame to a color space suitable for filtering, and identifies the average pixel position of the pendulum mass and the reference point. It uses these two positions to calculate the pendulum angle and estimates the angle uncertainty from the pixel-position uncertainty. The script skips the first 10 seconds of each video, processes up to 45 seconds of footage, removes the final 3 seconds of collected data, and saves the results in `outputs/position-data/`. Each output row contains the time, angle in radians, and angle uncertainty. Existing position-data files are skipped.

### `position-data-to-graphs.py`

This script reads the position-data files in `outputs/position-data/` and extracts the pendulum length and initial angle from each filename. For each trial, it fits the angle data to a damped harmonic motion model, determines the period from zero crossings, identifies the peak amplitudes, and calculates the damping factor and Q-factor. It also calculates uncertainties and groups trials with the same length and initial angle to find means, standard deviations, and uncertainties of the mean.

The script saves a position-versus-time graph and a peak-amplitude graph with residuals for each trial. It also creates graphs comparing period with length and initial angle, and Q-factor with length and initial angle. These graphs, along with their fitted models and error bars, are saved in `outputs/position-graphs/`, `outputs/peaks-graphs/`, `outputs/period-graphs/`, and `outputs/q-factor-graphs/`.

## Build Design Process
The considerations for th pendulum construction were to make it easy to align the starting position, easy to change the pendulum length, low visibility string, and easy for a program to identify the position of the mass and the position of the pivot point, which could be used to calculate the angle. I built the pendulum by creating a wooden frame with screws that could be used to tilt the frame. A backboard was placed with angle and distance markers, allowing easy pendulum setup and to create a solid background for the program. The mass was wrapped with green tape so a color filter algorithm could identify it. Similarly, the pivot point was marked with a blue marker.

## Program Design Process
When making the program, I needed to first be able to work with videos. After some testing, a color mask was able to reasonably find the positions of the mass and marker. The rest of the data processing was straightforward: read the data, plot it, fit a model, store the parameters of the model, plot the parameters for different data. To ensure everything was organized, I had to come up with a file naming convention, which is mentioned earlier. Most debugging was with the video processing. I had to cut out the start of the videos since it recorded my releasing the pendulum. Additionally, I kept 45 seconds of footage to keep it consistent and short.
